#   torch, sentence-transformers  — only the `local` embedding backend uses them, and

#       without it exercises the real fallback rather than mocking it.

# one of them at module scope, CI fails with an ImportError — which is the correct and
# loud outcome, since that would also break the 512MB deployment.
